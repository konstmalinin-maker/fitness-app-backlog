
# Definition of Done (DoD)

Задача считается выполненной, если:

- [ ] Код написан и прошёл код-ревью.
- [ ] Покрытие тестами составляет не менее 80%.
- [ ] Все тесты успешно проходят в CI.
- [ ] Документация обновлена.
- [ ] Функциональность проверена на staging.
- [ ] Product Owner принял результат.
